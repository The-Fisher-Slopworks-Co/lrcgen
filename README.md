# lrcgen

> 100% of the code in this repo was generated by AI. If that bothers you, save yourself the time.

Makes LRC files, with line and word timings, in your browser. Play a song and tap Enter as each line and word starts, fix what's off, then save the file next to the track or publish it to [LRCLIB](https://lrclib.net). Everything runs on your computer; `lrcgen` is a local server that opens a page.

## Install

Grab the binary for your OS from [Releases](https://github.com/txssu/lrcgen/releases). From source, with [Bun](https://bun.sh):

```bash
git clone https://github.com/txssu/lrcgen.git
cd lrcgen
bun install
bun link
```

## Usage

```console
$ lrcgen ~/Music/song.flac
lrcgen is running at http://127.0.0.1:4471
Press Ctrl+C to stop.
```

The browser opens on that song. Run `lrcgen` with no argument to browse for one. Work saves as you go, so you can close the tab and come back later. Save writes `song.lrc`, plus `song.enhanced.lrc` with the word timings, and keeps the old files as `.bak`.

Wireless headphones play late. Calibrate once from the latency badge in the footer, or your taps will land late too.

## AI transcription (optional)

lrcgen can transcribe the lyrics with line and word timings for you. It needs [uv](https://docs.astral.sh/uv/) and ffmpeg in `PATH`, plus an API key for an OpenAI-compatible service, OpenRouter by default. Set the key in Settings, or with `OPENROUTER_API_KEY` or `OPENAI_API_KEY`. The first run downloads several GB of dependencies and models.

## Files

- Drafts: `~/.local/share/lrcgen`
- Settings, including the API key: `~/.config/lrcgen/config.json`
- Separated vocals: `~/.cache/lrcgen`

These follow the `XDG_*_HOME` variables.
