# lrcgen

> 100% of the code in this repo was generated by AI. If that bothers you, save yourself the time.

Times song lyrics in your browser: when every line and word starts, and where it matters, when it stops. Play a song and tap Enter as each line and word starts, fix what's off on a timeline, split backing vocals and ad-libs off into groups of their own, then save next to the track (lrcgen's own lyrics file, plus LRC for players) or publish to [LRCLIB](https://lrclib.net). Everything runs on your computer; `lrcgen` is a local server that opens a page.

## Install

Grab the binary for your OS from [Releases](https://github.com/txssu/lrcgen/releases). From source, with [Bun](https://bun.sh):

```bash
git clone https://github.com/txssu/lrcgen.git
cd lrcgen
bun install
bun link
```

## Usage

```console
$ lrcgen ~/Music/song.flac
lrcgen is running at http://127.0.0.1:4471
Press Ctrl+C to stop.
```

The browser opens on that song. Run `lrcgen` with no argument to browse for one. Work saves as you go, so you can close the tab and come back later. Save writes `song.lyrics.json`, and for players `song.lrc` plus `song.enhanced.lrc` with the word timings (or just the `.lrc`, or no LRC at all); old files are kept as `.bak`.

Wireless headphones play late. Calibrate once from the latency badge in the footer, or your taps will land late too.

## The lyrics file

`song.lyrics.json` keeps everything lrcgen knows, and it's what lrcgen opens first when it finds one next to a track:

```json
{
  "format": "lrcgen-lyrics",
  "version": 1,
  "metadata": { "artist": "…", "title": "…", "album": "…", "tool": "https://github.com/txssu/lrcgen" },
  "groups": [
    { "id": "g1", "labels": [], "words": [
      { "id": "w1", "text": "Never", "start": 12000, "end": null },
      { "id": "w2", "text": "gonna", "start": 12480, "end": 13020 }
    ] },
    { "id": "g2", "labels": ["backing"], "words": [{ "id": "w3", "text": "ooh", "start": 12500, "end": 13100 }] }
  ]
}
```

- Every word belongs to exactly one group; groups and the words in them are in reading order. A group is usually a line; one with labels (any text: `backing`, `adlib`, `singer:A`…) is sung over or between the lines, and groups may overlap in time.
- Times are ms from the start of the song. `end` is usually `null`: the word lasts until the next one starts. It's set only where the voice stops before that, e.g. before a pause.
- A word's text may hold a space ("о разном"): it's sung as one and has one timing. `"noSpaceAfter": true` glues a word to the next (syllables).
- Ids are stable while you edit, so tools can point at words and groups.

LRC and Enhanced LRC (including `.enhanced.lrc` companions) are read too, and written for players: labelled groups go into the line they're sung with, in parentheses, and a pause after a word becomes an empty `<mm:ss.xx>` tag.

## AI transcription (optional)

lrcgen can transcribe the lyrics with line and word timings for you. It needs an API key for an OpenAI-compatible service, OpenRouter by default. Set the key in Settings, or with `OPENROUTER_API_KEY` or `OPENAI_API_KEY`. Nothing else to install: the first run downloads [uv](https://docs.astral.sh/uv/) (unless it's already in `PATH`), then several GB of Python dependencies and models.

If you already have the lyrics, **Sync my lyrics** on the Lyrics step lines them up with the vocals and gives every line and word a start, keeping your text as it is. It needs no API key.

## Files

- Drafts: `~/.local/share/lrcgen`
- Settings, including the API key: `~/.config/lrcgen/config.json`
- Separated vocals and the downloaded uv: `~/.cache/lrcgen`

These follow the `XDG_*_HOME` variables.
